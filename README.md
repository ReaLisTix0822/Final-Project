# ตลาดใจ: ตลาดกลางออนไลน์เพื่อผู้ที่มีความพิการ

**แพลตฟอร์มตลาดกลางออนไลน์สำหรับส่งเสริมการจำหน่ายสินค้าและสร้างรายได้ให้แก่ผู้พิการ**
Inclusive Handicraft Marketplace for People with Disabilities (IT 2569/WEB06)
สาขาวิชาวิทยาการคอมพิวเตอร์ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น

เว็บตลาดออนไลน์ที่ให้ช่างฝีมือผู้ที่มีความพิการ (และองค์กรที่ทำงานร่วมกับผู้ที่มีความพิการ) เปิดร้านขายงานฝีมือ
พร้อมเล่าเรื่องราวของชิ้นงาน ผู้ซื้อสนับสนุนได้ทั้งการซื้อสินค้าและเงินสมทบเพื่อพัฒนาอาชีพ
ทั้งเว็บออกแบบตามมาตรฐาน **WCAG 2.1 ระดับ AA**

## 1. เริ่มใช้งานใน 5 นาที

### สิ่งที่ต้องมี

| โปรแกรม | จำเป็นไหม | หมายเหตุ |
|---|---|---|
| [Node.js](https://nodejs.org) 18 ขึ้นไป | จำเป็น | ทดสอบกับ Node 22 |
| npm | จำเป็น | มากับ Node.js |
| MySQL / MariaDB (เช่น [XAMPP](https://www.apachefriends.org)) | ไม่บังคับ | ถ้าไม่มี ระบบใช้ SQLite ให้เอง |
| Google Chrome หรือ Microsoft Edge | แนะนำ | ใช้ทดสอบการสั่งงานด้วยเสียง |

### ขั้นตอน

```bash
# 1. ดาวน์โหลดโปรเจกต์
git clone https://github.com/ReaLisTix0822/Final-Project.git
cd Final-Project

# 2. ติดตั้งแพ็กเกจ
npm install

# 3. สร้างไฟล์ตั้งค่าจากตัวอย่าง (Windows ใช้: copy .env.example .env)
cp .env.example .env

# 4. เปิดเซิร์ฟเวอร์
npm start
```

5. เปิดเบราว์เซอร์ที่ **http://localhost:3000**

ครั้งแรกที่เปิดเซิร์ฟเวอร์ ระบบจะ**สร้างฐานข้อมูล ตาราง และข้อมูลตัวอย่างให้อัตโนมัติ** ไม่ต้อง import ไฟล์ SQL เอง
ถ้าเห็นข้อความแบบนี้ในเทอร์มินัลแสดงว่าพร้อมใช้งาน:

```
✅ [Database] Connected successfully to MySQL (localhost:3306/inclusive_marketplace)
🌟 Inclusive Marketplace Server running on port 3000
```

> ถ้าไม่ได้เปิด MySQL จะเห็น `MySQL not reachable locally ... Using embedded SQLite` แทน
> ใช้งานได้เหมือนกัน ข้อมูลจะอยู่ในไฟล์ `db/marketplace.sqlite`

### ใช้กับ XAMPP (แนะนำ ถ้าอยากดูข้อมูลใน phpMyAdmin)

1. เปิด XAMPP Control Panel แล้วกด **Start** ที่ MySQL
2. ค่าเริ่มต้นใน `.env.example` (ผู้ใช้ `root` ไม่มีรหัสผ่าน) ใช้กับ XAMPP ได้เลย
3. `npm start` แล้วเปิด http://localhost/phpmyadmin จะเห็นฐานข้อมูล `inclusive_marketplace`

## 3. ตั้งค่าไฟล์ .env

ไฟล์ `.env` **ไม่ถูกอัปขึ้น GitHub** (มีอยู่ใน `.gitignore`) ทุกคนต้องสร้างเองจาก `.env.example`

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `3000` | พอร์ตของเว็บ |
| `JWT_SECRET` | (ตัวอย่าง) | ใช้เซ็น token เข้าสู่ระบบ ควรเปลี่ยนเป็นข้อความสุ่มยาว ๆ |
| `DB_HOST` `DB_USER` `DB_PASSWORD` `DB_NAME` `DB_PORT` | `localhost` `root` (ว่าง) `inclusive_marketplace` `3306` | การเชื่อมต่อ MySQL |
| `DEMO_MODE` | `true` | แสดงปุ่มบัญชีทดลองในหน้าเข้าสู่ระบบ (ปิดเมื่อใช้งานจริง) |
| `GEMINI_API_KEY` | (ว่าง) | ไม่บังคับ: แชทบอทน้องใจดีและผู้ช่วย AI ถ้าไม่ใส่ ระบบตอบด้วยคำตอบสำรองในเครื่อง ขอคีย์ฟรีที่ [Google AI Studio](https://aistudio.google.com/apikey) |
| `GEMINI_MODEL` `GEMINI_CAPTION_MODEL` | `gemini-3.6-flash` | ชื่อโมเดล Gemini ที่ใช้ |
| `TRELLIS_API_KEY` `TRELLIS_ENDPOINT` | (ว่าง) | ไม่บังคับ: สร้างโมเดล 3D จากรูปสินค้า |

> **ห้ามใส่คีย์จริงลงใน `.env.example`** และห้าม commit ไฟล์ `.env`

## 4. ฐานข้อมูล

### ระบบเลือกฐานข้อมูลให้เอง

ตอนเปิดเซิร์ฟเวอร์ `config/database.js` จะทำตามลำดับนี้

1. ลองเชื่อมต่อ MySQL ตามค่าใน `.env` ถ้าสำเร็จจะสร้างฐานข้อมูลให้ (ถ้ายังไม่มี) แล้วรัน `db/schema.sql`
2. ถ้าเชื่อมต่อไม่ได้ จะใช้ SQLite ที่ไฟล์ `db/marketplace.sqlite` และรัน `db/schema.sqlite.sql`
3. ถ้ายังไม่มีข้อมูล จะใส่ข้อมูลตัวอย่างจาก `db/seed.js`
4. เพิ่มคอลัมน์ที่ขาดให้อัตโนมัติ (ปลอดภัย รันซ้ำได้ ไม่ลบข้อมูล)

ดังนั้น**ติดตั้งใหม่ไม่ต้องรัน migration เอง**

### ถ้ามีฐานข้อมูลเก่าอยู่แล้ว

ไฟล์ใน `db/migrations/` ใช้ปรับฐานข้อมูลที่สร้างไว้ก่อนหน้าให้ตรงกับโค้ดล่าสุด รันตามลำดับชื่อไฟล์ (รันซ้ำได้ ไม่ลบข้อมูล):

```bash
# ตัวอย่างบน macOS + XAMPP (Windows: C:\xampp\mysql\bin\mysql.exe)
/Applications/XAMPP/xamppfiles/bin/mysql -uroot inclusive_marketplace < db/migrations/20261027_accessibility_settings_columns.sql
```

| ไฟล์ | ทำอะไร |
|---|---|
| `2026-10-15-pdpa-consent.sql` | ความยินยอมเก็บข้อมูลความพิการ (PDPA มาตรา 26) และการปิดบัญชี |
| `2026-10-18-*.sql` | แก้ข้อมูลตัวอย่าง และผูกโมเดล 3D กับสินค้า |
| `20261019_align_32_tables*.sql` | ปรับให้ตรงกับการออกแบบ 32 ตารางในรายงาน (คำอธิบายใน `20261019_align_32_tables.md`) |
| `20261022_watermarked_images_placeholder.sql` | ซ่อนรูปสินค้าที่มีลายน้ำของเว็บอื่น ใช้รูปชั่วคราวแทน (ไม่ลบไฟล์) |
| `20261027_accessibility_settings_columns.sql` | เก็บการตั้งค่าช่วยการเข้าถึงทุกตัวลงบัญชีผู้ใช้ |
| `20261027_close_intellectual_seller_group.sql` | ปิดกลุ่มผู้ขายบกพร่องทางสติปัญญา ย้ายร้านไปกลุ่มองค์กร |
| `20261027_accessibility_tooltips.sql` | ตัวเลือก "คำอธิบายปุ่ม (Tooltips)" แทนโหมดเข้าใจง่าย |

### ดูข้อมูลในฐานข้อมูล

- **phpMyAdmin** (เมื่อใช้ XAMPP): http://localhost/phpmyadmin
- **คำสั่ง**: `npm run view-db` หรือ `node view-db.js products`
- **ในเว็บ**: เข้าสู่ระบบเป็นผู้ดูแลระบบ แล้วเปิด http://localhost:3000/db-viewer.html

### ข้อควรรู้

- XAMPP บางเวอร์ชันสร้าง stored procedure ไม่ได้ (ตาราง `mysql.proc` เก่า) migration ทุกไฟล์จึงไม่ใช้ stored procedure
- ไฟล์ที่ผู้ใช้อัปโหลด (`public/uploads/`) และเอกสารยืนยันตัวตนผู้ขาย (`private-uploads/`) **ไม่อยู่ใน Git**
  รูปสินค้าในข้อมูลตัวอย่างจึงมาจาก `public/images/` และลิงก์ภายนอก ถ้ารูปไหนหาไม่เจอ หน้าเว็บจะแสดงรูปสำรองแทน

├── routes/                   REST API แยกตามเรื่อง (/api/...)
│   ├── auth.js               สมัครสมาชิก เข้าสู่ระบบ บัญชีของฉัน ความยินยอม PDPA

│   └── ...                   (ai, chatbot, matching, reviews, campaigns, notifications ฯลฯ)

│   ├── schema.sqlite.sql     โครงสร้างตาราง SQLite
│   ├── seed.js               ข้อมูลตัวอย่าง
│   └── migrations/           ไฟล์ปรับฐานข้อมูลเก่า (ดูหัวข้อ 4)

## 7. ระบบช่วยการเข้าถึง (Accessibility)

เปิด **เมนูช่วยการเข้าถึง** ได้จากแถบสีเขียวด้านบนของทุกหน้า หรือกด `Alt + A`
ถ้าเข้าสู่ระบบอยู่ ค่าที่ตั้งจะบันทึกลงบัญชี (ตาราง `accessibility_settings`) ใช้ได้ทุกเครื่อง
ถ้ายังไม่เข้าสู่ระบบ จะเก็บไว้ในเบราว์เซอร์

| หมวด | ตัวเลือก |
|---|---|
| ขนาดตัวอักษร | ปกติ 100% / ใหญ่ 125% / ใหญ่มาก 150% (ปุ่ม "ก ก ก" บนแถบด้านบนใช้ค่าเดียวกัน) |
| การแสดงผล | ปกติ / คอนทราสต์สูง (เหลือง-ดำ) / ขาวดำ |
| ช่วยการอ่าน | เน้นลิงก์, ระยะห่างตัวอักษร, ฟอนต์อ่านง่าย (Atkinson Hyperlegible + Noto Sans Thai Looped), เคอร์เซอร์ใหญ่, หยุดภาพเคลื่อนไหว, คำอธิบายปุ่ม (Tooltips) |
| เสียง | อ่านออกเสียงตามโฟกัส, หยุดเสียงอ่าน, สั่งงานด้วยเสียง (ภาษาไทย), ความเร็วเสียงอ่าน ช้า / ปกติ / เร็ว |

ปุ่มลัดคีย์บอร์ด: `Alt + A` เมนูช่วยการเข้าถึง · `Alt + S` หยุดเสียงอ่าน · `Alt + B` แชทบอท · `Alt + H` หน้าแรก · `Esc` ปิดเมนู

ตัวอย่างคำสั่งเสียง: "หน้าแรก", "ดูสินค้า", "ค้นหา กระเป๋า", "ร้านค้า", "ตะกร้า", "จับคู่", "แชทบอท", "สมัครสมาชิก", "สมัครเป็นผู้ขาย"

หลักที่ใช้ทั้งเว็บ:
- ทุกสีมาจาก CSS variables ใน `public/css/main.css` โหมดคอนทราสต์สูงเปลี่ยนแค่ค่าตัวแปรเหล่านี้ (`public/css/accessibility.css`)
- ข้อความทุกจุดต้องมีความต่างของสีอย่างน้อย 4.5:1 (ข้อความใหญ่ 3:1) ตรวจด้วย `node scripts/check-contrast.js`
- ปุ่มและช่องกรอกสูงอย่างน้อย 44px ใช้คีย์บอร์ดได้ทุกจุด และมีกรอบโฟกัสสีเหลืองชัดเจน
- สถานะไม่บอกด้วยสีอย่างเดียว (มีไอคอนหรือข้อความประกอบเสมอ)

## 8. ความสามารถหลักของระบบ

- **ผู้ซื้อ**: ค้นหาด้วยข้อความหรือเสียง, กรองตามประเภทความพิการของช่างฝีมือ, ดูสินค้าแบบ 3D, ตะกร้า, สั่งซื้อพร้อมเงินสมทบให้ร้าน, ติดตามพัสดุ, รีวิว, ติดตามร้าน, แชทกับร้าน, ระบบจับคู่ร้านที่ตรงกับความสนใจ
- **ผู้ขาย**: สมัครพร้อมแนบเอกสารยืนยันตัวตน (รอผู้ดูแลอนุมัติ), จัดการสินค้า, ให้ AI ช่วยเขียนเรื่องราวสินค้าและกรอกข้อมูลจากรูป, จัดการคำสั่งซื้อและเลขพัสดุ, ตั้งเป้าหมายระดมทุนพัฒนาอาชีพ, ดูยอดขายย้อนหลัง
- **ผู้ดูแลระบบ**: ภาพรวมยอดขาย, อนุมัติ / ระงับร้านค้า, จัดการสมาชิก สินค้า รีวิว เรื่องร้องเรียน และแคมเปญ, ตั้งค่า AI
- **การชำระเงินเป็นแบบจำลอง** (PromptPay QR / บัตร / เก็บเงินปลายทาง) **ไม่มีการตัดเงินจริง**
- **ความเป็นส่วนตัว (PDPA)**: ข้อมูลประเภทความพิการเก็บเฉพาะเมื่อผู้ขายยินยอมโดยชัดแจ้ง, ผู้ใช้ขอปิดบัญชีและลบข้อมูลได้เอง, รายละเอียดอยู่ในหน้า `privacy.html`

## 10. ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `EADDRINUSE: address already in use :::3000` | มีเซิร์ฟเวอร์เปิดอยู่แล้ว ปิดตัวเก่า หรือเปลี่ยน `PORT` ใน `.env` |
| เทอร์มินัลขึ้นว่าใช้ SQLite แทน MySQL | ยังไม่ได้เปิด MySQL ใน XAMPP หรือค่า `DB_*` ใน `.env` ไม่ตรง (ใช้ SQLite ต่อได้ แต่จะไม่เห็นข้อมูลใน phpMyAdmin) |
| `npm install` ติดที่ `sqlite3` | ติดตั้ง Node.js เวอร์ชัน LTS ล่าสุดแล้วลองใหม่ (sqlite3 ใช้ไฟล์ที่คอมไพล์ไว้แล้วของ Node LTS) |
| แชทบอทตอบสั้น ๆ แบบเดิมทุกครั้ง | ยังไม่ได้ใส่ `GEMINI_API_KEY` ระบบจึงใช้คำตอบสำรองในเครื่อง |
| ปุ่มบัญชีทดลองไม่ขึ้นในหน้าเข้าสู่ระบบ | ตั้ง `DEMO_MODE=true` ใน `.env` แล้วเปิดเซิร์ฟเวอร์ใหม่ |
| สั่งงานด้วยเสียงไม่ทำงาน | ใช้ Chrome หรือ Edge เปิดผ่าน `http://localhost` (หรือ https) และกด "อนุญาต" ไมโครโฟน |
| แก้ไฟล์ใน `routes/` แล้วไม่เห็นผล | ต้องหยุดเซิร์ฟเวอร์ (Ctrl + C) แล้ว `npm start` ใหม่ |
| รูปที่เคยอัปโหลดหายหลัง clone | ไฟล์ใน `public/uploads/` ไม่อยู่ใน Git ต้องอัปโหลดใหม่ หน้าเว็บจะแสดงรูปสำรองแทนระหว่างนี้ |
